Option 3 — the [bread_mascot] shortcode

The WordPress-native answer: editors write a tag, the server renders the embed. No HTML knowledge required below the fold.

How it works on a real WordPress site

  1. Drop the PHP opposite into wp-content/mu-plugins/bread-mascot.php (always-on, no activation) or as a normal plugin — or paste it as a PHP snippet in the WPCode plugin.
  2. Host live.html once in uploads/bread-mascot/ (same as option 1).
  3. Anywhere shortcodes run — posts, pages, the Text widget, page- builder text fields — write [bread_mascot size="380" align="center"]. In PHP templates: <?php echo do_shortcode('[bread_mascot]'); ?>.
<?php
/*
Plugin Name:       Bread Mascot (shortcode)
Description:       Registers [bread_mascot] for the vendor-free mascot.
Version:           1.0
*/

// Assumes the file was placed (SFTP) at:
//   wp-content/uploads/bread-mascot/live.html
add_shortcode('bread_mascot', function ($atts) {
    $a    = shortcode_atts(['size' => 420, 'align' => 'center'], $atts);
    $url  = esc_url(content_url('uploads/bread-mascot/live.html'));
    $size = max(160, min(640, intval($a['size'])));
    return sprintf(
        '<div class="bread-mascot align%s" style="width:%dpx;max-width:100%%">'
      . '<iframe src="%s" title="Bread mascot" loading="lazy" '
      . 'style="width:100%%;aspect-ratio:1;border:0;border-radius:20px">'
      . '</iframe></div>',
        esc_attr($a['align']), $size, $url);
});

Notes

  • The shortcode outputs the option-1 iframe — deliberately: one hosted file, zero JS to manage. A variant can instead enqueue a split mascot.js and output a bare <div id>; that needs a generator change and cache-plugin exclusions, so start with the iframe.
  • Because expansion happens server-side, the shortcode also works in feeds and with page caches — unlike a client-side JS replacer.

About this demo

A static site that imitates a WordPress theme to show four ways of embedding the interactive bread mascot. GitHub Pages has no PHP, so wherever real WordPress would run code server-side, the demo says so and simulates it.

The mascot

  • One self-contained file, ~104 KB
  • No vendor runtime, no CDN, no account
  • Eyes follow the cursor (and get shy)
  • Click the loaf → chomp, the crate → Gockel
  • Leave → he sleeps, return → startle-wake

GDPR note

The mascot makes zero third-party requests and processes no data — embed it on EU sites without a cookie debate.
